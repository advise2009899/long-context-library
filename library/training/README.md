## 阅读路线

- 准备数据：文档组织 → 数据选择与配比 → 数据合成。
- 训练模型：继续预训练 → 指令微调 → 偏好优化或强化学习；这些阶段不要求所有模型依次经历。
- 控制成本：训练系统与效率；若改动模型结构，另看架构适配。
- 推理时更新模型：测试时训练与适配。
