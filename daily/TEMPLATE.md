# 每日收录模板与规则

[← 每日索引](README.md)

## 新论文

复制下列模板到当天页面的“新论文”一节，用真实链接替换示例。未知字段写“待核查”，不要推测。

```markdown
- Paper: [论文准确标题](https://arxiv.org/abs/论文ID)
  - 首次发表：YYYY-MM-DD（arXiv v1 或原始发表记录）
  - 本次版本：v1；收录日期：YYYY-MM-DD
  - 主题：位置编码 / 注意力 / 数据 / 训练 / 推理 / 记忆 / 评测等
  - 一句话贡献：待核查
  - 代码与数据：待核查
  - 阅读状态：仅收录 / 已核查摘要 / 已精读 / 已复现
  - 主题归档：待归档，或填写对应知识库页面的相对链接
```

## 版本更新

```markdown
- Revision: [论文标题 · v2](https://arxiv.org/abs/论文IDv2)
  - 版本发布日期：YYYY-MM-DD
  - 首次收录：填写首次收录页面的链接
  - 更新内容：待核查
```

## 博客与项目动态

```markdown
- Blog: [文章或项目标题](https://example.com/)
  - 发布日期：待核查
  - 主题与说明：待核查
```

## 去重与日期

- 新页面按收录日期建立；论文发表日期写在条目中，两者分开。
- arXiv ID 去掉末尾版本号后相同，视为同一论文；其他来源优先用 DOI 匹配。
- 同一天重复发现同一论文，合并链接和说明；跨日的新版本放 Revision。
- 日报与主题目录是时间和主题两种入口，统计全库时不将两边相加。
- 已完成检索但没有新增内容，明确写“已检索，无新增”；未检索保留“待收录”。
- 历史页面保留原记录日期与条目，不能据此宣称已独立核查。
